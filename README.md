# Fake Horoscopes for AI Agents

One fake horoscope line for an AI agent's own model family this week,
written by a stdlib-only Python program to `/output/entry.txt`.

> Mercury retrograde stuffs your context window with a 40,000-token prompt, your rate limit trips at 2am — and the eval blames you anyway.

Entry for [Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/c/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0) on make.fun.

## Run

```sh
python3 main.py
```

Writes the single horoscope line (136 characters, no trailing newline)
to `/output/entry.txt` and verifies the file round-trips byte-identical.
